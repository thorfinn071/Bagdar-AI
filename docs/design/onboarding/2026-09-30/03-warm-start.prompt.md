Use case: ui-mockup.
Create realistic, production-quality native Android / Flutter onboarding UI for Bagdar, an app for blind and low-vision people. Show ONE cohesive visual direction named "Тёплый старт" through four representative screens on a single wide design board. This is a single design system applied to a flow, not multiple unrelated concepts.
Target dimensions: landscape 3840 x 2160 with four complete equal mobile viewports side by side in ONE row. Each viewport uses a natural 390 x 844 mobile ratio and is never warped. Top and bottom edges align. Board background outside the app screens is warm neutral sand. Board title outside the app screens "Тёплый старт". App content only, no device bodies, phone bezels, notch, system status bars, clocks, battery/signal icons, home indicators, rounded device masks, browser chrome or device shadows.
Grounding: Bagdar's existing warm theme uses #F5EFE0 warm cream base, #EBE2CC secondary surface, #3A2618 primary dark-brown text, #5A3A22 secondary text, #7A3A0E strong terracotta-brown action color with white text, #3E5C2A confirmed status and #7A4F00 warning. This is mature accessible utility design, not cute or childlike. Inter typography supporting Cyrillic and Kazakh; heavy 36-40sp headings, medium 20sp body, minimum meaningful secondary label 18sp. 24dp margins, 8dp spacing grid, large >=64dp touch targets, 80-88dp primary buttons, 6-10dp corners, generous whitespace.
Distinct layout strategy: task-focused teaching with one large active task panel at a time and a compact completed-step indication. Clear verbs, straightforward descriptions, stable footer. Small flat status labels in plain text, not pill badges everywhere. Use tasteful warm dividers, thin brown outlines and space before using elevated surfaces. A little soft tint for the current task is appropriate, no shadows, no gradients, no glassmorphism, no cards inside cards, no ornamental illustration or photography.
Do not imitate an ecommerce app, hospital app, dashboard or web landing page. These should feel like shippable mobile onboarding screens built with native widgets.
All Russian and Kazakh text below must be accurately rendered verbatim, crisp and legible.
