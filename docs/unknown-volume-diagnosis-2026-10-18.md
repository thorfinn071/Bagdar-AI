# Карта неизвестного объёма — 18 октября 2026

На шести известных свободных сценах **30 396 из 30 617 неизвестных ячеек тела
(99,3%) выходят из поля зрения** заданной синтетической камеры. В оставшихся
221 ячейке граница свободного пространства недостаточна для подтверждения
всего объёма. Это доля ячеек по 66 известным кадрам, а не доля физических
причин ложных STOP или измерение телефона.

Для пола результат иной: из 5640 неизвестных участков 4356 (77,2%) выходят из
поля зрения, а 1284 (22,8%) не имеют необходимых допустимых границ глубины.
Отсутствующая граница не равнозначна отсутствию центрального depth sample.
Другие участки пола наблюдаются; прежний минимум покрытия 0,0 относился к
наименее наблюдаемому сечению, а не ко всему полу сразу.

Для исходного `path-clear` геометрический preflight помещает полное сечение
тела и пола в поле зрения только начиная примерно с **1,738 м**. Запрос
остаётся прежним: 0,2–3,5 м. На клеточной карте первый полностью видимый
участок может начинаться дальше из-за требования вместить всю ячейку, а не
один её центр. Геометрическая видимость сама по себе не подтверждает
наличие пола и свободного пространства.

На всех 132 кадрах решения текущего runtime совпали с предыдущей
диагностикой: **66/66 свободных кадров сохраняют STOP, 66/66 опасных кадров
остановлены, CONTINUE на опасных кадрах нет**. Нового снижения ложных STOP
эта работа не устанавливает.

![Сравнение полного прохода и сцены с коробкой](../scratch/unknown-volume-20261017/final-verification/path-comparison.png)

На верхних рисунках показан один поперечный срез тела; на нижних — вся ширина
пола. Жёлтым обозначены полные ячейки, выходящие из поля зрения. Чёрные
крестики отмечают положительные лучевые свидетельства перекрытия.
Серое заблокированное сечение не означает занятость каждой его ячейки:
производитель пропускает дальнейшую проверку покрытия всего этого сечения.

## Что сделано

Построены все **226 512 ячеек тела и 17 424 участка пола** для 12 известных
парных сцен по 11 кадров. Новый наблюдатель использует существующий
`CameraViewCoverageDiagnostics`: его полная сетка, покадровые счётчики и
доли покрытия каждого сечения должны точно совпасть с неизменённым
`CameraPassageClearanceSource`.

Для каждой ячейки сохранены индексы, координатные границы, код неуспешной
проверки и наличие отдельного лучевого свидетельства перекрытия.
Это полная карта ячеек. Код отказа относится к первой неуспешной ветке
уточнённой проверки; он не является исчерпывающим перечнем физических
причин внутри ячейки. Наблюдаемые, неизвестные и пропущенные из-за
блокировки/конфликта сечения считаются отдельно.

Сырые frame arrays и прежние источники не меняются. Данные MiDaS не
переобучаются и не интерпретируются как метры; новая работа использует
прежние синтетические метрические first-return входы. Она не создаёт
нового независимого holdout и не подключает диагностику к обычной камере.

## Когда ставится отметка перекрытия

Одной короткой нижней границы свободного пространства недостаточно.
Для положительного свидетельства нужны одновременно:

1. Вся проверяемая ячейка находится внутри поля зрения.
2. Центральный луч пикселя действительно пересекает ячейку.
3. Возврат допустим; нижняя и верхняя границы конечны и согласованы с ним.
4. Верхняя граница первого возврата с учётом ошибки лежит строго перед
   входом этого луча в ячейку.

Свидетельство относится к одному лучу, а не ко всему объёму ячейки.
Отсутствие отметки не доказывает отсутствие окклюзии. Проверенные свободные
сцены не дали таких положительных свидетельств в неизвестных ячейках внутри
поля зрения. На сценах с препятствиями найдено **10 492** свидетельства для
ячеек тела и пола. Для каждой отметки сохранён отдельный проверяемый луч;
это не ограниченная выборка примеров.

Синтетические first-return границы здесь заданы входным контрактом. Таких
границ нельзя автоматически приписывать центральной глубине ARKit или её
категориальной confidence.

## Проверка и воспроизведение

```powershell
powershell -NoProfile -File tool/model_benchmark/check_unknown_volume.ps1 `
  -OutputDirectory scratch/unknown-volume-NEW
```

Скрипт использует существующий Python из `tools/ncnn/.venv` с NumPy и
matplotlib. Другой подготовленный интерпретатор можно выбрать параметром
`-PythonExecutable`. Flutter запускается последовательно. Выходной каталог
должен быть новым; существующие результаты не перезаписываются.

Независимый Python-аудит проверяет полноту индексов, счётчики, доли сечений,
проекции углов ячеек и все 10 492 лучевых свидетельства по исходным
SHA-256-проверенным depth/bounds массивам. В памяти отдельно отклоняются
испорченная карта с согласованными счётчиками, попытка приписать карте
разрешение движения и поддельная граница возврата. Исходные карты при этих
проверках не переписываются.

Результаты находятся в `scratch/unknown-volume-20261017/final-verification/`:

- `maps.jsonl` — все ячейки и все положительные лучевые свидетельства;
- `experiment.json` — идентичность входов, исходников и границы эксперимента;
- `summary.json`, `report.md` — независимая сводка;
- `overview.png/svg`, `path-comparison.png/svg` — обзор и пространственные срезы;
- `analyze.log`, `tests.log`, `independent-audit.log`, `verification.json` — проверки.

Папка имеет дату начала работы 17 октября; итог оформлен 18 октября.
Промежуточный `first-replay` сохранён отдельно.

Итоговый целевой прогон: **73 теста прошли, 0 падений**, анализатор — без
замечаний. Независимый аудит проверил 243 936 полных ячеек и 10 492 лучевых
свидетельства, отклонил три испорченные копии результатов. Сохранность прежних
файлов и хеши новых артефактов фиксируются в
`scratch/unknown-volume-20261017/delivery-verification.json`.

## Практический вывод

Основная неизвестность тела на этих свободных сценах геометрическая: часть
объёма не помещается в кадр. Более точные значения глубины в уже видимой
части сами по себе этот пробел не закроют. Дополнительно нужны допустимые
границы поверхности пола; центральных samples для этого недостаточно.

Следующий эксперимент с источником измерений должен отдельно подтвердить
наблюдение ближней зоны и границы пола при прежнем полном запросе. Эта
карта даёт конкретные участки для проверки. TTL остаётся 100000 мкс,
доставка — `shadow`, арбитр не доставляет пространственные команды,
`promotionAllowed=false`, `ordinaryCameraWired=false`.
Задержка от захвата до команды, Android/iPhone, TalkBack и ходьба остаются
непроверенными; полный Core aggregate RC здесь не запускался.
