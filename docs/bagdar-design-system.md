# Единый интерфейс Bagdar AI

Обновлено: 12 октября 2026.

Основой служит выбранный ранее нативный onboarding: спокойные формы, Inter,
светлый нейтральный фон и тёмно-зелёный акцент. Общие компоненты адаптируются
к тёмной, светлой, тёплой и высококонтрастной палитрам. Сохранённая тема и
существующий тёмный вариант по умолчанию продолжают действовать.

## Источник оформления

| Ответственность | Файл |
| --- | --- |
| Цвета, шрифт, размеры, геометрия, движения, сигналы поверх камеры | `lib/theme/bagdar_tokens.dart` |
| Material-компоненты и применение выбранной темы | `lib/theme/bagdar_theme.dart` |
| Общая страница и непрозрачная карточка | `lib/widgets/bagdar_ui.dart` |

`BagdarThemeScope` применяет одну палитру и одну Material-тему, включая
загрузку и восстановление onboarding. Системный высокий контраст имеет
приоритет. Изолированное превью onboarding использует ту же светлую тему.

## Визуальные правила

| Элемент | Правило |
| --- | --- |
| Шрифт | Локальный Inter с кириллицей и казахскими буквами |
| Заголовок страницы | 32, Bold, высота строки 1.2 |
| Заголовок секции | 20, Bold |
| Основной текст | 18, высота строки 1.5 |
| Подписи и пояснения | 16, высота строки 1.5 |
| Кнопка основного действия | 18, Bold, минимальная высота 64 dp |
| Иконки | Material, стандартный размер 24 dp |
| Внешний отступ | 24 dp |
| Ширина читаемой колонки | Не более 560 dp |
| Скругления | Кнопки/поля 12, карточки 16, панели 20 dp |
| Иерархия действий | Заливка для основного, контур для вторичного |

В сложных экранных сценариях остаются специализированные размеры:
например, предупреждения, прогресс и сигналы на камере. Обычные кнопки и
иконки имеют область активации не менее 48 dp; основные действия — 64 dp.

`divider` разделяет группы декоративно. `controlBorder` используется для
контура интерактивных элементов и имеет самостоятельную проверку контраста.
Статусы сохраняют текст, форму и иконку. Нельзя сообщать состояние только цветом.

## Что приведено к общей системе

- Загрузка, восстановление и все шаги onboarding.
- Панель действий осмотра и Material-диалоги, включая SOS и форму контакта.
- Настройки речи, сигналов, языка и оформления; выбор темы сохраняется.
- Технические настройки обработки собраны в раскрываемую группу диагностики.
- QR-экспорт и импорт, языковые пакеты, экраны карт и сохранённых мест.
- Туториал и другие компоненты, уже использующие общие токены, получают
  обновлённые шрифт, геометрию и палитру через тему.

Заголовок QR-страницы прокручивается вместе с содержимым. Предпросмотр
импорта расположен под камерой и доступен при крупном тексте. Подтверждение
импорта удержанием сохранено. QR-код сохраняет белую подложку во всех темах,
а рамка на видеопотоке использует отдельный контрастный токен камеры.

## Проверка

Результат проверок сохранён в
`output/design-unification-2026-10-12/validation.json`.

Основной прогон: 328 тестов прошли. Финальный прогон интерфейса и общих
компонентов: 90 тестов прошли, включая 63 проверки дизайн-системы. Прогоны
частично пересекаются, их количества не суммируются.

`flutter analyze --no-pub lib test/theme_test.dart test/design_system_widget_test.dart`
завершился без замечаний. Общий запуск анализатора также захватил архивные
копии кода в `output/` и посторонние lint-замечания в
`test/volume_authority_regression_test.dart`; его нельзя считать чистым
анализом всего рабочего каталога. Копии исходников этой работы сохранены
с расширением `.dart.txt`; настройки исключения диагностики не менялись.

Проверяется контраст основного текста, подписей, контуров управления и
сигналов во всех четырёх темах. UI-матрица охватывает RU/KK/EN, текст 200%,
портрет и альбомную ориентацию; отдельно проверяются диагностика на планшете,
QR-предпросмотр, смена/сохранение темы и системный высокий контраст.

Повторно проверены существующие тесты допуска к осмотру, восстановления,
переходов между страницами, SOS и резервирования настроек. Правила допуска,
подтверждения сигналов и отправки SOS этой работой не изменяются.

Физическое устройство, TalkBack на Android, реальная камера/сканирование и
физическая обратная связь в рамках этой работы не проверялись. Экраны карт
и мест сохраняют существующие ограничения профиля Core.
