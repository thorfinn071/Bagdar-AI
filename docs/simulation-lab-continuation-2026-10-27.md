# Bagdar: завершение пакетной симуляции

Дата этапа: 27 октября 2026 года.

В текущем прогоне предпринято **72/72 эпизодов**. Полные отчёты приложения: **72**; доставлено **2232 кадров**.

Получено **115 результатов YOLO**, выполнено **64 запросов глубины**. Контроллер принял **55 результатов глубины**. Принятый результат не означает, что подтверждена проходимость.

## Что изменилось

- Автоматический пакет запускает тот же APK отдельным процессом для каждого независимого эпизода. Каждый клип длится две секунды; после подачи входа есть три секунды для завершения обработки. Внутри эпизода сохраняются исходный темп кадров и штатное состояние алгоритмов. Этот тест не проверяет длительную непрерывную работу.
- Переход между эпизодами не требует завершения анимации или закрытия Flutter-экрана. Для каждого запуска проверяются идентификатор прогона, сцена и хеш входного набора.
- Есть ограничение ожидания отчёта, прогресс, журналы Android и отдельная запись тайм-аутов. Тайм-аут не подменяется выдуманным отчётом приложения.
- Навигационный режим оставлен опциональным: widget-тесты переходов проходят, но native-проверка выявила незавершённое закрытие экрана при ANR Android. Его не следует считать исправленным для всех условий.

## Следующий измеримый этап

Оценивать распознавание непригодных кадров и ложные отбрасывания раздельно; проверять влияние на решения всего конвейера. Сначала зафиксировать протокол и новую контрольную выборку, затем рассматривать изменения фильтра.

**Границы результата:** debug APK, x86_64 Android-эмулятор, CPU YOLO/NCNN и процедурные Blender-сцены. Калибровка камеры, реалистичность сенсорной модели, реальные телефоны, TalkBack и контролируемая ходьба этим прогоном не подтверждены. Геометрия и разметка не подавались в модели; MiDaS остаётся относительной глубиной. `promotionAllowed=false`, доставка геометрических подсказок — `shadow`.
